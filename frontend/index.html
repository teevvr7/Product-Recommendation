1. Problem Statement & Objective

Acme Retail requires a production-grade product similarity and recommendation system that moves beyond simple exact keyword matching. The system accepts either plain product search text or an existing catalog product ID, represents items in a continuous vector space capturing semantic meaning, computes cosine similarity, and returns the top-N ranked items.

2. End-to-End Processing Pipeline

Stage 1: Preprocessing Combines title, main category, and subcategory. Applies regex cleaning, tokenization, stopword removal, and WordNet lemmatization.
Stage 2: OOV Detection Analyzes incoming tokens against the Word2Vec vocabulary. If all tokens exist, selects Word2Vec; if any unseen/typo token is found, triggers FastText.
Stage 3: Embedding Synthesizes 100-dimensional dense embeddings by averaging constituent word vectors or subword character n-grams (3-6 chars).
Stage 4: Cosine Ranking Executes L2-normalized dot product across pre-computed catalog matrices in <5ms. Extracts top-N items arranged by similarity score.

3. Rationale: Word2Vec Primary + FastText Fallback

Why Word2Vec as Primary? Word2Vec (Skip-gram, window=5, vector_size=100) creates high-precision semantic representations for catalog titles and categories, learning rich e-commerce relationships (e.g., brand associations, product types).

Why FastText as Fallback? In a real-world e-commerce marketplace, customers frequently misspell search terms (e.g. bluetoth instead of bluetooth, wireles instead of wireless) or search for brand names and slang not present in training data. Word2Vec produces an all-zero vector for out-of-vocabulary words. FastText resolves this using character n-grams (3 to 6 characters), reconstructing vectors from subword morphology and ensuring recommendations never fail.

4. High-Performance Retrieval Math

Rather than re-computing vector norms during every user query, the catalog embeddings (63,333 × 100) are L2-normalized at server startup: 

normalized_matrix = matrix / np.linalg.norm(matrix, axis=1, keepdims=True)
query_norm = query / np.linalg.norm(query)
similarity_scores = np.dot(normalized_matrix, query_norm.T).flatten()  # Runs in ~4.6ms on 63K products!
